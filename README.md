## The joke

> Finance rejected my $4 pen — it needed a manager's signature — so we spent $214 of salaries in a meeting to approve it, and Dave signed it with Finance's own pen.

A three-beat office micro-narrative: the $4 pen request gets rejected for want of a signature, a $214 meeting is convened to approve it, and Dave — the second character — signs it with Finance's own pen.
